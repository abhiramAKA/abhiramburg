## ⚔️ 2. РАБОЧИЕ ГЕЙМПЛЕЙНЫЕ МЕХАНИКИ

1. **Расширенное поле 8х8:** Сетка игрового поля успешно расширена до формата 8х8 ячеек. Интегрированы адаптивные стили против схлопывания контейнера.
2. **Система Очков Действия (ОД / AP):** Игрок имеет 3 ОД на раунд. Каждый результативный ход на поле тратит 1 ОД.
3. **Тактический боевой цикл:** После обнуления ОД игрока ход автоматически переходит к Дракону. Дракон наносит точечный урон (20 ед.) по случайному герою. Каждые 3 раунда активируется массовая фаза — *Дыхание Рока* (35 ед. урона по всему отряду).
4. **Ультракомпактный интерфейс отряда:** Показатели здоровья Воина (`⚔️`) и Клирика (`💚`) переведены из тяжелых карточек в лаконичные значки с цифрами в один горизонтальный ряд, освобождая пространство экрана.
5. **Динамическая зона босса:** Реализована анимированная зона Дракона с багровой подложкой и текстовым бэкап-аватаром `🐉`. Он покачивается в режиме ожидания (`dragon-idle`) и совершает рывок при атаке (`dragon-attacking`), активируя визуальный оранжевый поток огня.
