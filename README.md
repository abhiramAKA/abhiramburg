## 🔄 ОБНОВЛЕНИЯ ВЕРСИИ v0.6.0-BETA (РЕЗУЛЬТАТЫ ТЕКУЩЕЙ СЕССИИ)

Ниже зафиксированы все архитектурные и геймплейные изменения, внедренные в ходе текущей сессии разработки. Проект полностью переведен на стабильный рельс ветки v0.6.0-beta.

### 1. Визуальный сок (Juice) и Графика
* **Увеличение рун:** Базовый размер шрифта эмодзи-рун на игровом поле увеличен с `20px` до `26px`. Сетка полностью адаптирована под новый размер, исключая деформацию и распирание соседних блоков или элементов управления.
* **Эффект Гравитации (Вводное появление):** Полностью заменено старое падение рун «вертикальной кучей» при старте матча. Реализована плавная анимация `runeIntro` — руны элегантно проявляются из центра шахматной волной с масштабированием (`fade-in-scale`) и микро-задержками. Падение сверху вниз (`rune-fall`) теперь включается только для новорожденных рун в процессе игры.

### 2. Анимации и Частицы (JS + CSS Keyframes)
* **Анимация Взрыва:** При уничтожении комбинаций руны больше не исчезают мгновенно. Срабатывает анимация `runeExplosion` — перед удалением из DOM камень за 0.22 секунды увеличивается в размерах, вспыхивает и плавно растворяется.
* **Дизайнерские Искры (Система частиц):** Написан полностью динамический генератор искр на чистом JS + CSS без картинок. Из центра каждой взорванной руны во все стороны разлетаются 8 магических искр, которые затухают на лету (`sparkFade`).
* **Адаптивная палитра частиц:** Цвет искр подстраивается под тип взорванной руны: огонь (🔥) дает пламенно-оранжевые искры, молния (⚡️) — ярко-желтые, жизнь (💚) — изумрудно-зеленые, защита (🛡️) — лазурно-голубые, а смерть (💀) — фиолетовые.

### 3. Звуковое сопровождение и Виброотдача (Audio & Haptics)
* **Процедурный аудио-движок:** Интегрирован модуль `Web Audio API`. Звуки генерируются математическим кодом на лету (синтезаторы `sine`, `triangle` и `sawtooth`), что избавляет проект от необходимости скачивать тяжелые `.mp3` файлы.
* **Аудио-эффекты:** Добавлен кристальный перезвон при начальном проявлении поля, короткий щелчок скольжения при перемещении рун и низкочастотный сочный взрыв при комбо.
* **Тактильный отклик (Haptic Feedback):** Интегрирован вызов `navigator.vibrate(60)`. При взрыве комбинаций на мобильных устройствах Android игрок физически ощущает сочную виброотдачу.

### 4. Новые Механики и Ввод (Управление)
* **Система Свайпов (Жесты):** Внедрена кроссплатформенная система трекинга жестов смахивания. Игра успешно считывает события `touchstart/touchmove` для смартфонов и `mousedown/mousemove` для ПК. Игрок может менять руны местами как кликами, так и свайпами.
* **Плавный Своп и Своп-бэк:** При обмене руны плавно летят навстречу друг другу (`transition: transform`). Если комбинация не собралась, они совершают сочный упругий отскок назад на свои места.
* **Триумфальное возвращение Мага:** В глобальный стейт `combatData` и в боевой интерфейс полностью возвращен третий играбельный персонаж — Маг (⚡️) с его честными 80 единицами здоровья.

### 5. Изменения Интерфейса (UI/UX)
* **Информационные справочники:** На боевой экран (панель босса) добавлена компактная кнопка `❓`, вызывающая всплывающее тактическое окно с описанием правил боя и точного значения каждого камня.
* **Оживление Главного Меню:** Кнопки «Кузница» (⚒️), «Алхимия» (🧪) и «Отряд» (👥) теперь активны, подсвечиваются готическим золотым сиянием и при нажатии открывают ЛОР-описания грядущих игровых модулей.

### 6. Архитектурное разделение кода (Strict Module Separation)
Для предотвращения переполнения памяти и исключения обрезки кода файлы были строго разделены по зонам ответственности:
* `index.html` — Чистая разметка и версионные хвостовики (`?v=beta10`) против кэширования.
* `game.js` — Центральный диспетчер стейта и переключения экранов.
* `match3.js` — Только логическое ядро игры (матрица, проверка совпадений, клики).
* `match3-input.js` — Отдельный модуль трекинга мыши и свайпов.
* `match3-fx.js` — Отдельный модуль генерации процедурного звука, вибрации и искр.
* `css/board.css` — Сетка поля, геометрия ячеек 26px и CSS-анимации.

## 📁 1. АРХИТЕКТУРА И СОСТАВ ФАЙЛОВ ПРОЕКТА

### Исходный код (Корень проекта):
* **`index.html`** — Чистый скелет разметки окон. Содержит структуру Главного меню, Экрана контекстной справки и Боевого экрана. Не содержит жесткого кода игровых элементов — вся динамика строится через JS.
* **`game.js`** — Центральный диспетчер стейта и данных. Хранит глобальный объект состояния `combatData`, параметры отряда героев, матрицу поля и координирует бесшовный метод переключения экранов `showScreen`.
* **`match3.js`** — Модуль игрового поля. Отвечает за генерацию сетки рун 8х8 без готовых комбинаций, обработку кликов игрока, перемещение (своп / своп-бэк) и алгоритм поиска совпадений.
* **`combat.js`** — Пошаговый тактический движок. Динамически собирает зону Дракона, рассчитывает урон и лечение от собранных комбинаций рун, управляет Очками Действия (AP) и ИИ Босса.
* **`background.js`** — Автономный модуль атмосферы. Отвечает за рендеринг живого фона и искр костра на холсте `canvas`.

### Модульные стили (Папка `css/`):
* **`styles.css`** (в корне) — Диспетчер стилей. Содержит только импорты субмодулей с флагами версий против кэширования браузером.
* **`css/base.css`** — Базовые настройки экрана, сброс отступов, шрифты и готические эффекты золотого сияния кнопок.
* **`css/layouts.css`** — Геометрия окон, выравнивание элементов через Flexbox, кнопка справки `❓` и параметры живого фона.
* **`css/combat.css`** — Интерфейс боя, багровый радиальный градиент зоны Дракона, анимации парения (`dragonFloat`) и извержения пламени (`burnEffect`).
* **`css/board.css`** — Настройки строгой адаптивной сетки поля Match-3 размером 8х8 (`grid-template-columns: repeat(8, 1fr)`).

## ⚔️ 2. РАБОЧИЕ ГЕЙМПЛЕЙНЫЕ МЕХАНИКИ

1. **Расширенное поле 8х8:** Сетка игрового поля успешно расширена до формата 8х8 ячеек. Интегрированы адаптивные стили против схлопывания контейнера.
2. **Система Очков Действия (ОД / AP):** Игрок имеет 3 ОД на раунд. Каждый результативный ход на поле тратит 1 ОД.
3. **Тактический боевой цикл:** После обнуления ОД игрока ход автоматически переходит к Дракону. Дракон наносит точечный урон (20 ед.) по случайному герою. Каждые 3 раунда активируется массовая фаза — *Дыхание Рока* (35 ед. урона по всему отряду).
4. **Ультракомпактный интерфейс отряда:** Показатели здоровья Воина (`⚔️`) и Клирика (`💚`) переведены из тяжелых карточек в лаконичные значки с цифрами в один горизонтальный ряд, освобождая пространство экрана.
5. **Динамическая зона босса:** Реализована анимированная зона Дракона с багровой подложкой и текстовым бэкап-аватаром `🐉`. Он покачивается в режиме ожидания (`dragon-idle`) и совершает рывок при атаке (`dragon-attacking`), активируя визуальный оранжевый поток огня.
